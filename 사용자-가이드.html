01앱 개요

AutoEmbed LAB은 독일 자동차 임베디드 석사 과정 지원을 목표로 하는 사람을 위해 설계된 웹 애플리케이션입니다. 차량용 임베디드(CAN, LIN, AUTOSAR, FreeRTOS, 모터 제어 등) 프로젝트를 만들고, 독일 대학 정보를 조사하고, 지원 서류와 면접을 준비하는 전체 과정을 하나의 화면에서 관리할 수 있습니다.

포트폴리오 빌더14개 큐레이션 프로젝트 + 코드 랩 + 스타터팩 ZIP 생성
대학 정보10개 독일 대학 프로그램·연구소·산업 연계 데이터
지원 전략바이에른 GPA 환산, 대학 요구사항 매칭, 경쟁력 진단
서류·면접자기소개서·이력서·Lebenslauf 생성, 모의 면접 40+ 질문
실습 환경브라우저 C 컴파일러(Compiler Explorer), 오프라인 인터프리터, 시리얼 통신
학습 관리로드맵 8단계, 체크리스트, 배지, 활동 스트릭, 다국어 지원
데이터 저장 안내모든 데이터는 브라우저 localStorage에 중앙 집중식으로 저장됩니다. 서버가 없으므로 인터넷 없이도 동작하며, 백업 기능을 주기적으로 사용하세요.

02시작하기 (설치·실행)

Node.js(20 이상 권장)가 설치되어 있다면 아래 명령으로 바로 실행할 수 있습니다.

npm install        # 의존성 설치
npm run dev        # 개발 서버 실행 (http://localhost:5173)
명령동작
npm run devVite 개발 서버 실행 (핫 리로드)
npm run build프로덕션 빌드 생성 (단일 HTML 파일 번들)
npm run testVitest 테스트 실행 (120+ 테스트 케이스)
안정성에러 바운더리(Error Boundary)가 적용되어 렌더링 중 예외가 발생해도 앱 전체가 크래시되지 않고 안전하게 복구됩니다.

04다국어 및 접근성

전 세계 사용자 및 다양한 환경을 고려한 인프라가 구축되어 있습니다.

다국어 지원 (i18n)

  • 3개 국어 — 한국어(ko), 독일어(de), 영어(en)를 지원합니다.
  • 언어 전환 — 우측 상단의 언어 스위처를 통해 즉시 변경할 수 있습니다.
  • 지능형 초기화 — 브라우저 언어 설정을 감지하여 최적의 언어로 시작합니다.

접근성 보장 (Accessibility)

  • Reduced Motion — 애니메이션에 민감한 사용자를 위해 prefers-reduced-motion을 감지하여 애니메이션을 자동으로 억제합니다.
  • 포커스 관리 — 탭 전환 시 화면 상단으로 스크롤하고 제목으로 포커스를 이동시켜 키보드 내비게이션을 돕습니다.
  • 스크린 리더 최적화 — aria-label 및 role 속성을 통해 보조 기술 사용자를 위한 정보를 제공합니다.

08내 포트폴리오

저장한 프로젝트를 관리하고 진행 상황을 추적하는 탭입니다.

  • GitHub 배포 (Git Data API) — 스타터팩 구성을 GitHub 저장소에 단일 커밋으로 고속 배포합니다. 수십 개의 파일을 순차적으로 푸시하지 않고 한 번에 업데이트하여 배포 시간을 획기적으로 단축했습니다.
  • 진행 트래커 — 프로젝트별 완료 태스크를 기록합니다.
  • 활동 스트릭 — 매일의 학습 기록을 시각화합니다.

10코드 랩

브라우저에서 C 코드를 작성·실행·분석하는 실습 환경입니다.

오프라인 C 인터프리터 확장

네트워크 없이도 동작하는 내장 인터프리터가 이제 더 복잡한 C 문법을 지원합니다.

  • 구조체 지원 — struct 정의 및 멤버 접근(. 연산자)을 지원합니다.
  • Enum/Union — enum 상수의 자동 증감 및 union 기본 선언을 지원합니다.
  • 타입 시스템 — typedef를 통한 사용자 정의 타입을 인식합니다.
코드 스플리팅React.lazy를 적용하여 각 탭의 코드는 필요할 때만 로드됩니다. 초기 로딩 속도가 개선되었습니다.

16데이터 저장·백업·쿼터

중앙 집중식 스토리지 관리 시스템이 도입되었습니다.

  • 중앙 레지스트리 — 17개 이상의 localStorage 키가 storage.ts에서 통합 관리됩니다.
  • 스키마 검증 — 백업 복원 시 데이터 구조가 올바른지 검증하여 앱 오동작을 방지합니다.
  • 용량 경고 — 브라우저 스토리지 쿼터(약 5MB)의 80%를 초과할 경우 사용자에게 알림을 표시하여 데이터 유실을 방지합니다.

18자주 묻는 질문

Q. 폰트가 왜 평소와 다른가요?

외부 CDN 의존도를 낮추기 위해 폰트 셀프 호스팅을 적용했습니다. Pretendard와 JetBrains Mono를 로컬에서 서빙하며, 로드 실패 시 시스템 폰트(Windows/Mac/iOS/Android 최적화)로 자동 전환됩니다.

Q. GitHub 배포 시 토큰이 안전한가요?

입력한 Personal Access Token은 브라우저 메모리에만 일시적으로 머물며, 배포 완료 즉시 초기화되어 제거됩니다. 또한 autocomplete="off"를 적용하여 보안을 강화했습니다.
