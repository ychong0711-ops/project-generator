01앱 개요

AutoEmbed LAB은 독일 자동차 임베디드 석사 과정 지원을 목표로 하는 사람을 위해 설계된 웹 애플리케이션입니다. 차량용 임베디드(CAN, LIN, AUTOSAR, FreeRTOS, 모터 제어 등) 프로젝트를 만들고, 독일 대학 정보를 조사하고, 지원 서류와 면접을 준비하는 전체 과정을 하나의 화면에서 관리할 수 있습니다.

포트폴리오 빌더14개 큐레이션 프로젝트 + 코드 랩 + 스타터팩 ZIP 생성
대학 정보10개 독일 대학 프로그램·연구소·산업 연계 데이터
지원 전략바이에른 GPA 환산, 대학 요구사항 매칭, 경쟁력 진단
서류·면접자기소개서·이력서·Lebenslauf 생성, 모의 면접 40+ 질문
실습 환경브라우저 C 컴파일러(Compiler Explorer), 오프라인 인터프리터, 시리얼 통신
학습 관리로드맵 8단계, 체크리스트, 배지, 활동 스트릭, 백업/복원
데이터 저장 안내모든 데이터(저장 프로젝트, 코드, 진단 결과, 통계)는 브라우저 localStorage에 저장됩니다. 서버가 없으므로 인터넷 없이도 동작하며, 브라우저를 바꾸거나 캐시를 지우면 데이터가 사라질 수 있으니 백업 기능을 주기적으로 사용하세요.

02시작하기 (설치·실행)

Node.js(18 이상)가 설치되어 있다면 아래 명령으로 바로 실행할 수 있습니다.

npm install        # 의존성 설치
npm run dev        # 개발 서버 실행 (http://localhost:5173)
명령동작
npm run devVite 개발 서버 실행 (핫 리로드)
npm run build프로덕션 빌드 생성 (단일 HTML 파일로 번들)
npm run preview빌드 결과 미리보기
npm run testVitest 단위 테스트 실행 (8개 테스트 파일)
빌드 산출물이 프로젝트는 vite-plugin-singlefile을 사용해 빌드 결과가 단일 HTML 파일로 생성됩니다. GitHub Pages 등 정적 호스팅에 그대로 올릴 수 있습니다.

10코드 랩

브라우저에서 C 코드를 작성·실행·분석하는 실습 환경입니다. 프로젝트별 샘플 코드로 시작해 직접 수정하며 학습할 수 있습니다.

에디터 기능

  • 문법 하이라이트 — 키워드(보라)·숫자(하늘)·전처리(자홍)·주석/문자열(회색/호박) 컬러링
  • 컴파일 오류 표시 — 오류 라인(빨강)·경고 라인(호박) 배경 강조
  • Tab 들여쓰기 — Tab 키로 들여쓰기
  • Ctrl+Enter 실행 — 빠른 실행 단축키
  • 라인 점프 — 특정 라인으로 이동
  • 자동 저장 — autoembed-code-{projectId} 키로 코드 자동 저장

컴파일러 (온라인)

Compiler Explorer(godbolt.org) API를 연동해 실제 ARM 크로스 컴파일러로 빌드합니다.

컴파일러설명
armg1320arm-none-eabi-gcc 13.2.0 (ARM Cortex-M)
armg1413arm-none-eabi-gcc 14.1.3
armg1421arm-none-eabi-gcc 14.2.1
cg142gcc 14.2 x86-64 (데스크톱)

기본 플래그: -O1 -Wall -mcpu=cortex-m4 -mthumb

오프라인 C 인터프리터

인터넷 없이도 C 코드를 실행할 수 있는 내장 인터프리터입니다.

  • 지원: int/double/char, 배열, 기본 포인터, 함수, if/for/while/do-while/switch, printf(%d %u %x %X %f %.2f %e %g %c %s, 폭·정밀도·0 패딩), 수학/문자열/메모리 내장 함수
  • 미지원: struct/enum/typedef, 전역 초기화식, 2차원 배열, sizeof
  • 자동 검증: 기대 출력(expect)이 모두 포함되면 (PASS) 표시

AI 멘토 정적 분석

코드를 정적으로 분석해 품질 점수와 개선 가이드를 제공합니다.

  • 9종 검사: 누락 헤더(stdio/stdint/math/string — 원클릭 수정), gets() 금지, strcpy/strcat 경고, main() 없음, 중괄호 불균형, 0 나눗셈, 미초기화 변수, 매직 넘버, 무한 루프, 주석 비율
  • 점수 공식: 100 − 오류×18 − 경고×6 − 정보×2 (0~100)
  • MISRA-C 품질 점수: 매직 넘버, 함수 40줄 초과, 블록 중첩 3단 이상, goto, 3줄 중복 블록
  • 프로젝트 핵심 요소 체크리스트: 15개 프로젝트별 필수 구현 요소(예: can-uds-scanner → CRC-15 다항식 0x4599, UDS SID, NRC 0x7F) 대비 커버리지 % 산출
  • 멘토 요약 리포트: 점수별 코멘트, 오류/경고 우선순위, 커버리지, 프로젝트 팁, 다음 단계

GCC 에러 지식베이스

13개 규칙으로 컴파일 오류를 자동 해석합니다: 미선언 식별자, 암시적 함수 선언, 세미콜론/괄호 구문 오류, 중복 정의/타입 충돌, 링커 undefined reference, 헤더 없음, 타입 불일치, 인자 개수, lvalue 오류, 잘못된 포인터 연산, unused variable, 반환 없는 경로, 포인터↔정수 변환 — 각각 원인/해결/학습 포인트 제공(최대 2개 매칭).

11실측 랩 (SerialLab)

Web Serial API를 이용해 실제 MCU 보드와 브라우저를 시리얼로 연결해 데이터를 수집·시각화합니다.

  • 시리얼 연결 — Web Serial API 기반, 브라우저에서 포트 선택
  • Baud rate — 115200 / 57600 / 38400 / 9600
  • 라벨 프리셋 — t_ms, soc_pct, rpm, temp_c, v_bat, adc_raw, distance_cm
  • 실시간 플롯 — 최대 1200 포인트, 560×180 그래프
  • 노이즈 필터 — none / ma(이동평균) / ema(지수이동평균) / median
  • 캘리브레이션 — none / manual / 2pt(2점 보정)
  • 윈도우 크기 — 3 / 5 / 10 / 20
  • 펌웨어 템플릿 — MCU 측 시리얼 출력 펌웨어 제공 (serial/firmware.ts)

  • 풀이 완료 기록 — autoembed-repo-solved

교재 트랙 (TextbookTracks)

저작권을 침해하지 않도록 원문 문제·그림·코드 없이 챕터 주제(커리큘럼 구조)만 참고하고, 문제는 전부 자체 제작한 3개 트랙 12장 구성입니다.

  • 임베디드 C 기초 → 차량 통신 (5장): 비트 연산/데이터 해석, 합 체크섬·CRC, 디바운스, LIN 기초, PID
  • 차량 신호 처리·수치 검증 (4장): 노이즈 필터링, ADC·양자화, LUT 보간, 휠 슬립
  • 실시간 시스템 기초 (3장): RMS 스케줄링 가능성, 주기 입력 처리, 워치독

각 장은 목표(goals) + 연결 실습(labIds) + 연결 프로젝트(projectIds)로 구성되어 학습 흐름을 따라갈 수 있습니다.

독일 대학 지원의 핵심인 성적 환산과 대학 매칭을 자동으로 계산합니다.

독일 GPA = 1 + 3 × (max − score) / (max − minPass)   (1.0 ~ 4.0 클램프)
독일 등급의미

동일한 구성을 GitHub 원클릭 배포(GitHubDeploy)로 바로 저장소에 올릴 수도 있습니다.

18자주 묻는 질문

Q. 데이터가 사라졌어요. 어떻게 복구하나요?

백업 파일(autoembed-backup-*.json)이 있다면 "내 포트폴리오 → 백업 → 가져오기"로 복원할 수 있습니다. 백업 파일이 없다면 브라우저 캐시 삭제로 인한 데이터 손실은 복구할 수 없습니다.

Q. 코드 랩에서 컴파일이 안 되는데 인터넷이 필요하나요?

온라인 컴파일(Compiler Explorer)은 인터넷이 필요합니다. 하지만 오프라인 C 인터프리터를 사용하면 인터넷 없이도 대부분의 예제를 실행하고 PASS/FAIL 검증을 받을 수 있습니다.

Q. 시리얼 연결이 안 돼요.

Web Serial API는 Chrome/Edge에서만 지원됩니다. Firefox·Safari에서는 동작하지 않으며, HTTPS 또는 localhost 환경에서만 포트 접근이 허용됩니다.

Q. GitHub 저장소 탐색이 갑자기 안 돼요.

GitHub API의 미인증 요청 제한(분당 10회)에 걸렸을 수 있습니다. 1분 정도 기다린 후 다시 시도하세요.

Q. 독일 GPA 환산은 어떻게 하나요?

"경쟁력 센터 → 지원 전략"에서 바이에른 공식(1 + 3×(max−score)/(max−minPass))으로 자동 계산됩니다. 1.0~4.0 범위로 클램프되며 sehr gut/gut/befriedigend/ausreichend 등급으로 표시됩니다.

Q. 자기소개서 점수를 높이려면?

구체성 스코어러 기준으로 ① 구체적인 숫자와 단위 ② 프로젝트 코드(DE-EMB-XXXX) ③ 지원 대학 언급 ④ 충분한 분량을 채우면 점수가 올라갑니다. 5문항 인터뷰에 실제 경험 기반으로 답하세요.

Q. APS 인증이 필요한가요?

한국 국적 지원자는 APS 인증이 불필요합니다. 다만 uni-assist/VPD 인증은 대학에 따라 필요할 수 있으니 로드맵 D-6개월 단계를 확인하세요.
