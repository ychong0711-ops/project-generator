## 2. union 경고 — 무엇을 했나

### 배경

`src/offline/interpreter.ts`의 `makeAggCell()`은 union의 스칼라 멤버들이 **하나의
`numCell`을 공유**하도록 만듭니다. 같은 크기의 정수 계열끼리는 대체로 맞지만,

- `union { float f; int i; }` 처럼 **타입을 재해석**하는 경우
- `union { int w; char b[4]; }` 처럼 **바이트 단위로 오버레이**하는 경우

는 실제 C와 다른 값을 냅니다. 문제는 이때 **오류 없이 조용히 틀린 값**이 나온다는 점이었습니다.

### 선택한 방침 (A안)

근사 구현은 그대로 두되, union 인스턴스가 만들어지면 결과에 경고를 함께 반환합니다.
정확한 바이트 레이아웃이 필요하면 온라인 모드(arm-gcc)로 검증하도록 안내합니다.

`ArrayBuffer` + `DataView` 기반 정식 구현(B안)은 인터프리터의 값 모델(`Cell`)을
바꿔야 해서 범위가 큽니다. 앱이 제공하는 C 샘플·실습 코드에 union 사용이 0건이라
비용 대비 효과가 낮다고 판단했습니다.

### 변경 사항

```
src/offline/interpreter.ts        OfflineResult.warnings 추가, UNION_APPROX_WARNING 상수,
                                  CInterpreter.warn() (중복 제거), makeAggCell에서 경고 기록
src/components/OfflineWarnings.tsx  (신규) 경고 표시 공통 컴포넌트
src/components/CodeLab.tsx        오프라인 실행 콘솔에 경고 표시 (성공/실패 모두)
src/components/LabExercises.tsx   동일
src/components/RepoExplorer.tsx   동일
src/offline/interpreter.test.ts   테스트 4건 추가
```

API는 **하위 호환**입니다. `warnings`는 선택 필드이고, 경고가 없으면 아예 붙지 않습니다
(`undefined`). 기존 `ok` / `output` / `steps` / `error`의 의미는 그대로입니다.

```ts
export interface OfflineResult {
  ok: boolean;
  output: string;
  steps: number;
  error?: { line: number; message: string };
  warnings?: string[];   // 신규
}
```

### 동작 규칙

- union 변수(또는 union 배열/중첩 멤버)가 생성되는 **런타임 시점**에 기록합니다.
  선언만 하고 쓰지 않으면 경고가 나오지 않습니다.
- 같은 경고는 **몇 번 발생하든 1건**만 쌓입니다.
- 실행이 도중에 실패해도 이미 발생한 경고는 결과에 남습니다.

## 3. 화면에서 확인하는 법

`npm run dev` → **CodeLab** 탭 → 에디터에 아래 코드를 붙여넣고 **⚡ 오프라인 실행**:

```c
#include <stdio.h>
union U { int a; char b; };
int main(void) {
    union U v;
    v.a = 65;
    printf("%d %d\n", v.a, v.b);
    return 0;
}
```

출력(`65 65`) 아래에 호박색 경고 박스가 뜨면 정상입니다.

> 브라우저가 이전 번들을 캐시하고 있으면 경고가 안 보일 수 있습니다.
> **Ctrl+Shift+R**(하드 리로드)로 강제 새로고침하세요.

1. **PR 병합** — 승인 권한은 사용자에게 있습니다.
2. **`git pull` 후 로컬 확인** — Windows 환경 확인은 여전히 사용자 몫입니다.
   ```bash
   git checkout main
   ```

   ```bash

   git push
   ```
